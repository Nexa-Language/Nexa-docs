# 项目与社区

Nexa 的语言、文档、终端助手与编辑器扩展由各自仓库协同维护。

| 项目 | 入口 |
| --- | --- |
| 语言与运行时 | [Nexa](https://github.com/Nexa-Language/Nexa) |
| 双语文档 | [Nexa-docs](https://github.com/Nexa-Language/Nexa-docs) |
| 终端编程助手 | [Nexa-Code](https://github.com/Nexa-Language/Nexa-Code) |
| 编辑器扩展 | [Nexa-extension](https://github.com/Nexa-Language/Nexa-extension) |
| 网站 | [nexa-lang.com](https://www.nexa-lang.com) |

在对应仓库提出 issue，并按[贡献指南](contribution.md)附复现与验证信息。本站提供 Material 搜索、语言切换和源码入口；反馈通过仓库 issue 处理。
