# Projects and community

Nexa's language, documentation, terminal assistant, and editor extension are maintained in coordinated repositories.

| Project | Entry |
| --- | --- |
| Language and runtime | [Nexa](https://github.com/Nexa-Language/Nexa) |
| Bilingual documentation | [Nexa-docs](https://github.com/Nexa-Language/Nexa-docs) |
| Terminal coding assistant | [Nexa-Code](https://github.com/Nexa-Language/Nexa-Code) |
| Editor extension | [Nexa-extension](https://github.com/Nexa-Language/Nexa-extension) |
| Website | [nexa-lang.com](https://www.nexa-lang.com) |

Open issues in the relevant repository with reproduction and validation details from [Contributing](contribution.md). This site provides Material search, a language switch, and source links. Repository issues are the feedback channel.
