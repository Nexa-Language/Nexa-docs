# Contributing

Documentation, runtime, and tools live in separate Nexa-Language repositories. Before contributing, identify the component, runtime version, and reproduction path.

- [Nexa](https://github.com/Nexa-Language/Nexa): language, compiler, runtime.
- [Nexa-docs](https://github.com/Nexa-Language/Nexa-docs): bilingual docs and checks.
- [Nexa-Code](https://github.com/Nexa-Language/Nexa-Code): terminal coding assistant.
- [Nexa-extension](https://github.com/Nexa-Language/Nexa-extension): VS Code extension.

## Documentation changes

Keep Chinese and English topics and capability coverage aligned. Register the validation mode of each Nexa code block. Update source/test provenance with capability claims, and run strict builds, links, and example checks. The documentation repository README contains exact commands.

## Bug reports

Include a minimal reproduction, version, command, expected result, and actual result. Remove credentials and task data. For uncertain tool side effects, preserve the local checkpoint and submit a sanitized summary.
